# Bildschirmauflösungen, an denen ein Bildschirmfoto zu erkennen ist.
#
# Diese Datei ist die EINE Stelle. Sie wird von tools/bestand.py gelesen und
# von dort auch vom Ingest benutzt (ingest/einordnen.py bindet die Funktion
# ein, statt sie nachzubauen). Eine Liste im Code müsste jemand beim nächsten
# Gerät im Quelltext suchen; hier steht sie zum Nachtragen.
#
# Format: BREITExHOEHE, dahinter frei der Gerätename. Alles ab # ist Kommentar,
# Leerzeilen sind erlaubt.
#
# QUERFORMAT MUSS NICHT EINGETRAGEN WERDEN. Jede Zeile gilt in beiden
# Richtungen – wer die gedrehte Fassung von Hand nachtragen müsste, vergisst
# sie irgendwann bei genau einem Gerät.
#
# -------------------------------------------------------------------------
# WAS HIER NICHT HINEINGEHÖRT, UND WARUM
#
# Die Auflösung allein entscheidet nichts – es zählt die Kombination aus
# passenden Maßen UND fehlendem `Make`. Trotzdem ist die Liste die
# gefährlichste Stelle: ein Format, das auch als Zielgröße von Messengern oder
# als übliche Bildgröße vorkommt, macht aus Fotos ohne EXIF stillschweigend
# Bildschirmfotos. Deshalb nur, was unverwechselbar ein Bildschirm ist.
#
# Bewusst NICHT aufgenommen, am Bestand nachgemessen:
#
#   1080x1920   iPhone Plus. Zugleich die verbreitetste Videoauflösung
#               überhaupt: von 1.023 Zeilen mit diesen Maßen sind 1.013
#               Videos. Das Kriterium `typ = 'bild'` fängt die Videos schon
#               ab, aber Full-HD ist auch bei Standbildern (Netzfunde,
#               Hintergrundbilder) zu gewöhnlich, um etwas zu beweisen.
#
#   1024x768    Klassische Verkleinerungsgröße von Messengern und alten
#   768x1024    Digitalkameras. Im Bestand 51 Zeilen, keine davon erkennbar
#               ein Bildschirmfoto.
#
#   750x1624    Im Bestand 41 PNG ohne `Make` – vermutlich wirklich
#               Bildschirmfotos, aber von keinem iPhone: das Format gehört zu
#               keiner bekannten Apple-Auflösung. Wer sie einordnen will,
#               klärt erst, woher sie kommen, und trägt sie dann hier ein.
#
# Lieber ein Bildschirmfoto zu wenig erkannt als ein Foto falsch einsortiert.
# Nachtragen ist eine Zeile, Zurückholen ist ein Nachlauf über den Bestand.
# -------------------------------------------------------------------------
